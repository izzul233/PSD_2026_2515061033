# Pengurutan Transaksi Pengeluaran Harian Berdasarkan Jumlah Nominal
# Deskripsi
Pengelolaan keuangan yang baik berawal dari pencatatan dan analisis pengeluaran yang terstruktur. Dalam kehidupan sehari-hari, kita seringkali mencatat berbagai transaksi secara acak tanpa memperhatikan urutan nominalnya. Hal ini terkadang membuat kita kesulitan saat ingin mengevaluasi pengeluaran—misalnya saat mencari tahu transaksi mana yang paling hemat, atau sekadar melihat pola pengeluaran harian kita.
Proyek ini dibangun sebagai solusi praktis untuk masalah tersebut, sekaligus menjadi sarana implementasi konsep struktur data dan algoritma dasar menggunakan bahasa pemrograman Python.
Secara teknis, program ini melakukan dua hal utama yang pertama itu Manajemen Data yaitu Memanfaatkan struktur data List of Dictionaries di Python untuk menyimpan informasi transaksi secara berpasangan, yaitu mengaitkan deskripsi transaksi (string) dengan jumlah nominalnya (float).
