# E Commers
# DESKRIPSI
Di era e-commers yang serba cepat, pengelolaan tata letak barang di dalam gudang sering kali menjadi tantangan besar yang memicu inefisiensi operasional. Sistem Manajemen Gudang E-Commerce berbasis Binary Search Tree (BST) ini hadir sebagai solusi cerdas untuk mendigitalisasi dan mengotomatiskan penempatan ID produk ke dalam struktur rak penyimpanan. Dengan memanfaatkan struktur data pohon biner, sistem ini mampu menghilangkan proses pencarian barang manual yang melelahkan, memastikan setiap pasokan barang baru langsung mendapatkan posisi idealnya secara instan, serta memangkas waktu kerja petugas gudang secara signifikan.

Inti dari efisiensi sistem ini terletak pada kemampuannya mengorganisasi ruang penyimpanan secara logis menggunakan prinsip navigasi otomatis. Setiap produk yang masuk akan diidentifikasi melalui ID uniknya, di mana barang pertama yang didaftarkan akan bertindak sebagai pusat jangkar utama (root) di tengah gudang. Produk dengan ID yang lebih kecil secara otomatis diarahkan oleh sistem ke koridor cabang sebelah kiri, sedangkan produk dengan ID yang lebih besar akan mengisi koridor cabang sebelah kanan. Pola distribusi biner ini memastikan bahwa tata letak gudang selalu terurut secara sistematis, sehingga mempercepat waktu akses ke tiap-tiap produk.

Selain penataan otomatis, sistem ini dilengkapi dengan fitur-fitur operasional esensial untuk mempermudah manajemen stok harian. Melalui fungsi pelacakan tetangga terdekat (successor dan predecessor), petugas dapat dengan mudah mengetahui produk apa saja yang berada tepat di sekitar posisi rak tertentu untuk kebutuhan optimasi ruang atau pengelompokan barang sejenis. Ketika suatu produk habis terjual, sistem dapat menghapusnya secara aman tanpa merusak hierarki penempatan yang ada berkat algoritma rekonstruksi pohon yang cerdas. Terakhir, fitur peninjauan per lapisan (level-order traversal) memberikan gambaran transparan mengenai struktur tata letak gudang dari lantai teratas hingga terbawah untuk mempermudah inspeksi fisik secara berkala.

# PENJELASAN CODE
Struktur kode ini dibangun menggunakan paradigma pemrograman berorientasi objek di dalam bahasa Python untuk merepresentasikan tata letak gudang secara digital. Komponen paling mendasar dari sistem ini adalah kelas Node, yang berfungsi sebagai cetak biru untuk setiap slot penyimpanan atau kotak barang individu di dalam rak gudang. Di dalam kelas ini, terdapat tiga variabel utama yang diinisialisasi saat sebuah objek baru dibuat. Variabel pertama bernama key, yang digunakan untuk menyimpan ID produk berupa angka unik sebagai dasar utama pengurutan posisi di dalam pohon biner. Dua variabel berikutnya adalah left dan right, yang awalnya bernilai None. Kedua variabel ini bertindak sebagai penunjuk arah atau konektor yang akan menghubungkan kotak rak saat ini dengan kotak rak lainnya yang berada di lapisan bawahnya, baik ke cabang sebelah kiri untuk barang dengan nilai lebih kecil maupun ke cabang sebelah kanan untuk barang dengan nilai lebih besar.

Untuk memasukkan barang baru ke dalam gudang, sistem menyediakan fungsi insert yang bekerja sama dengan fungsi rekursif insert_node. Alur kerja fungsi ini sangat logis karena selalu mengecek dari kondisi teratas gudang, yaitu variabel root. Jika sistem mendeteksi bahwa gudang masih dalam keadaan kosong atau nilai root adalah None, maka produk pertama tersebut akan langsung ditetapkan sebagai jangkar pusat atau fondasi utama dari seluruh struktur pohon biner. Namun, jika sudah ada produk yang menempati posisi pusat tersebut, fungsi rekursif akan mulai bekerja membandingkan ID produk baru dengan ID produk yang sudah ada di rak saat ini. Ketika ID produk baru bernilai lebih kecil, program akan memanggil kembali dirinya sendiri untuk bergeser memeriksa cabang sebelah kiri. Sebaliknya, jika ID produk baru bernilai lebih besar, program akan bergerak menyusuri cabang sebelah kanan. Proses perbandingan dan perpindahan jalur ini akan terus berulang secara otomatis ke lapisan yang lebih dalam hingga sistem menemukan slot kosong yang pas, lalu menancapkan node baru tersebut di sana dan memperbarui hubungan konektor dari node di atasnya.

Fitur pencarian tetangga terdekat diimplementasikan melalui dua fungsi penting yang bernama successor dan predecessor. Kedua fungsi ini dirancang menggunakan perulangan while untuk memastikan proses pencarian berjalan sangat cepat dan hemat memori karena langsung menyusuri jalur pohon tanpa perlu melibatkan fungsi rekursif yang berat. Fungsi successor bertugas mencari ID produk terdekat yang nilainya berada tepat di atas ID yang sedang diperiksa. Di dalam kode, proses ini dilakukan dengan cara berjalan ke arah kiri setiap kali menemukan node yang nilainya lebih besar dari target, sembari menyimpan koordinat node tersebut ke dalam variabel succ sebagai kandidat terkuat. Di sisi lain, fungsi predecessor bekerja dengan logika berkebalikan untuk menemukan ID produk terdekat yang nilainya berada tepat di bawah ID target. Fungsi ini akan bergerak ke arah kanan setiap kali menemukan node yang nilainya lebih kecil dari target, kemudian mencatatnya dalam variabel pred. Melalui mekanisme pelacakan ini, petugas gudang bisa mendapatkan informasi instan mengenai barang apa saja yang posisinya mengapit rak tertentu demi efisiensi pergerakan fisik saat pengambilan barang.

Operasi penghapusan data produk yang telah habis terjual ditangani oleh fungsi delete dan delete_node yang merupakan bagian paling kompleks dalam sistem ini. Ketika perintah hapus dijalankan, fungsi pertama-tama akan melakukan navigasi pencarian dengan membandingkan ID target untuk bergerak ke kiri atau ke kanan hingga posisi node yang dimaksud berhasil ditemukan. Setelah node target ditemukan, sistem harus mengevaluasi tiga skenario struktur yang berbeda agar pohon tidak terputus. Skenario pertama dan kedua terjadi jika node yang akan dihapus tidak memiliki anak sama sekali atau hanya memiliki satu anak di salah satu sisinya. Jika tidak memiliki anak, node tersebut langsung dieliminasi dengan mengembalikan nilai None ke node di atasnya. Jika hanya memiliki satu anak, anak tersebut akan langsung dioper ke atas untuk mengambil alih posisi node yang dihapus, sehingga hubungan antar rak tetap tersambung dengan rapi.

Skenario ketiga dari penghapusan terjadi apabila node yang ingin dihilangkan memiliki dua anak sekaligus di sisi kiri dan kanannya. Untuk mengatasi hal ini tanpa mengacaukan aturan pohon biner, sistem akan memanggil fungsi min_node untuk mencari nilai terkecil yang ada di seluruh cabang sebelah kanan node tersebut. Nilai terkecil ini, yang dikenal sebagai ahli waris, dijamin merupakan angka yang paling aman untuk ditaruh di posisi tengah menggantikan node yang dihapus. Setelah nilai ahli waris berhasil disalin ke posisi node lama, sistem akan melakukan operasi pembersihan lanjutan dengan menghapus node ahli waris asli yang berada di lapisan bawah agar tidak terjadi duplikasi data.

Setelah seluruh proses penghapusan selesai, sistem menyediakan fungsi level_order untuk menampilkan struktur gudang terbaru dari lantai paling atas hingga lantai terbawah. Fungsi ini memanfaatkan struktur data antrean dari pustaka collections yang bekerja dengan prinsip antrean barisan, di mana node pusat akan dimasukkan terlebih dahulu, dicetak nilainya, lalu anak-anaknya dimasukkan ke antrean belakang untuk diproses pada giliran berikutnya, sehingga menghasilkan tampilan visual tata letak rak yang berurutan per lapisan lantai gudang.
